# Phoebus Screens

These files provide a GUI interaction with the soft IOCs via [Phoebus/CS-Studio](https://controlssoftware.sns.ornl.gov/css_phoebus/).

`multi_opi.bob` creates an instance of `waveforms.bob` for each supported target.
`waveforms.bob` opens two pages for the same IOC (buttons in its right-hand column), generated by
`python3 epics/gen_screens.py` (`--channels 16 --suffix _16` for 16-channel boards):

- `rfdc_nco.bob`: per-ADC and per-DAC NCO RF frequency and phase, with the resulting NCO frequency and Nyquist zone.
- `dac_control.bob`: per-DAC waveform length, mode, CW amplitude and phase and the common apply (IOCs with one
  waveform generator per DAC, e.g. `mimo-5g-zcu208-ioc`).
